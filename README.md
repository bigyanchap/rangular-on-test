# rangular-test-project

This project has one page.
The page has nine discs.
The discs test one question.
Is the dead top right corner in the Rangular framework, or only in the tutorial app?

## What is on the page

- The page has three rows.
- Each row has three discs.
- Each disc is 40 by 40.
- Each disc is blue: #0b57d0.
- Each disc shows one number, 1 to 9.
- A line under the rows reads: Tapped:
- Tap a disc.
- The disc number appears in the Tapped line.

The grid is an exact copy of the grid probe in the tutorial repo.
Source branch: unpinned-bar-test.
Source commit: b5f018c5.
Source files: src/lesson.component.html and src/lesson.component.ts in that repo.
In the tutorial, the grid sits at the top of the lesson page.
Only the root screen sits above the grid there.
In this project, only the root screen sits above the grid too.
This project has no app bar.
This project has no menu.
This project has no other page.

## How to read the result

- Tap the discs in order, 1 to 9.
- Read the Tapped line.
- If the line reads 1 2 3 4 5 6 7 8 9, all discs work in this project.
- Then the dead corner is specific to the tutorial app.
- If the 3 is missing, disc 3 is dead in this project too.
- Then the dead corner sits in the framework or in Expo, not in the tutorial app.
- Send the numbers in the Tapped line back.

## Run the project on your Mac

1. Put this project beside your rangular-framework clone.
2. Open a terminal.
3. Go to the folder above both projects.
4. Clone this repo:

    git clone https://github.com/bigyanchap/rangular-test-project.git

Note: if the clone fails because the GitHub repo is not there yet, copy the rangular-test-project folder to your Mac instead, and start at step 5.

5. Go into the project:

    cd rangular-test-project

6. Install the packages:

    npm install

7. Build the app with the Rangular CLI:

    rg build

8. Check the output.
9. The output must say it wrote src/AppRoot.tsx.
10. Start Expo:

    npx expo start

11. Wait for the QR code.
12. Open Expo Go on your iPhone.
13. Scan the QR code.
14. Wait for the page to load.
15. See nine blue discs at the top of the page.
16. Tap disc 1.
17. Tap disc 2.
18. Tap disc 3.
19. Tap disc 4.
20. Tap disc 5.
21. Tap disc 6.
22. Tap disc 7.
23. Tap disc 8.
24. Tap disc 9.
25. Read the Tapped line.
26. Write down the numbers in the line.
27. Send the numbers back.

## Notes for the run

- Your rg command is your zsh function.
- The function points at the built CLI in your rangular-framework clone.
- Run npm install in packages/cli first if the CLI does not start.
- Run npm run build in packages/cli next.
- Then run rg build again in this project.
- This project carries the framework ui and runtime packages in its vendor folder.
- The vendor copy comes from the rangular-framework repo, packages/ui and packages/runtime.
- So this project runs from a plain clone.
- It does not need a sibling folder with a set name.

## Files

- src/app.component.ts holds the class, the styles, and the mark method.
- src/app.component.html holds the grid and the Tapped line.
- src/AppRoot.tsx is generated by rg build.
- Do not edit src/AppRoot.tsx by hand.
- Edit the two source files, then run rg build again.
